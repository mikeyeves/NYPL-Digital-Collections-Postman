# NYPL Digital Collections API - Postman collection

The New York Public Library [Digital Collections API](https://api.repo.nypl.org/) (v2). Free token required.

## Import
In Postman: **Import > Link** and paste
`https://raw.githubusercontent.com/mikeyeves/NYPL-Digital-Collections-Postman/main/NYPL_Digital_Collections_API.postman_collection.json`

## Requests
| Request | Use |
|---|---|
| Search items / in a field | find maps, directories, photos |
| Item by UUID, MODS, item details | metadata and image links for a digitalcollections.nypl.org item |
| Collections | list collections |
